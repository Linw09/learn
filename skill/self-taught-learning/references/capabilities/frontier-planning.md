# 超前学习规划（Frontier Learning Planning）

> 一句话：在你当前该学的进度之外，主动、有范围地提前学后面更难的东西，并把"学到多深"分层管理——让别人预习时，你已经在复习。

## R — 原文 (Reading)

> "超前学习法就是领先当前这个阶段应该学习的内容，提前学未来更难的知识。通过持续的超前学习，在任何有限游戏中都可以轻易胜出。"（源文本附条件：智商只要不差太多）
>
> "别人在预习的时候，他已经在复习了。"
> — 第18讲

> "你现在学这门课，之前的有限游戏课程如果是 100% 的话，那么现在超前学习的可能到 50%，下一个课程 30%，再往后 10%，再后面 1%，会呈现一个漏斗的形状。"
> — 第18讲

> "超前学习一定要注意范围管理……范围不能太广……可以少，但是不能多，就叫做宁缺毋滥……第一次用超前学习法呢，你在有限游戏以外学一门课。"
> — 第18讲

> "超前学习未必要完全看懂、完全学会，但是一定要看出知识的大致框架，看出重要的方法，然后要学会最基础的知识。"
> — 第18讲

## I — 方法论骨架 (Interpretation)

超前学习不是"预习"（预习跟着课程进度走），而是**自建进度**：领先当前阶段，提前啃后面更难的内容。它的整套操作围绕四个机制：

1. **漏斗形知识结构**——用深度分层取代"门门都精"：旧课 100% 滚瓜烂熟，超前一层约 50%，再往后 30% → 10% → 1%（只记得名字）。日拱一卒把上游逐步推上去，永远保持漏斗形；不要求这门前置课全学完才开下一门。
2. **框架把握法**——先抓骨架再填血肉。取框架的四个点：① 目录；② 前言 + 每章开头；③ 每节首句；④ 听课的话第一节课（讲什么、用什么方法）。附带收益：比较不同教材/老师的框架，能判断谁理解更深。
3. **重点定位**——两条客观线索：① **反复提及/反复使用的即重要**（可用 PDF 词频排序辅助，如勒贝格理论高频词是"测度/外测度"）；② **学下一门课是学这门课的最好方法**（看下游课反复用什么，就知道本课重点）。
4. **范围管理 + 节奏**——第一次只超前**一门**课，宁缺毋滥；先保质保量完成主业（有限游戏），再谈超前；用**日拱一卒**把长期目标切成每天一小步；发现方向错就早纠偏（三角不等式：越早转亏越少）。

**底层框架**（完整展开见 `motivation-engine`——该框架的唯一归属卡）：单门课/单本讲义是**有限游戏**（有终点，可项目管理），整体成长是**无限游戏**（无限个有限游戏叠加）。脱离学校后没有天然的目标与对手，需要**人为创造有限游戏**（打卡、找对手、定目标）。

## A1 — 讲者案例 (Past Application)

### 案例 1：初中自学微积分、高中啃大学实分析/拓扑（第18讲，亲述）
- 问题：年龄/知识难度的"常规"限制似乎不可逾越
- 做法：在正常学段之外，主动提前学大学数学（微积分、实分析、点集拓扑）
- 结论：年龄与难度不构成绝对限制，但要求"意志足够坚定、内心足够强大"

### 案例 2：高中生→大学数学的思维断层（第18讲，演示）
- 问题：高中数学好 ≠ 能适应大学数学（ε-δ、全称/存在量词）
- 做法：提前自学一点大学分析学，先适应新语言
- 结论：超前学习的意义之一是"提前适应新思维方式"，而非只抢进度

### 案例 3："很多人超前学习的结果是超前放弃"（第18讲，转述直播间观众）
- 问题：目标过大、摊子铺太广
- 结论：这是范围管理"宁缺毋滥"的反向证据——超前学习失败的主因不是难度，而是范围失控

### 案例 4：一本书读前 10 页等于没读（第18讲，转述合作者阿U木）
- 问题：以为"我在看书"就是学习
- 结论：书的内容非均匀分布，开头介绍性内容知识密度几乎为零；开坑不学完 = 白学（用于论证"必须学完一个区间"）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力？

1. 「我想自学 X，帮我规划一下先学什么、学到什么程度」——尤其是有明确的后续课程/目标时
2. 「我看后面的课完全看不懂，是不是该先补点什么」
3. 「我想提前学，但不知道从哪下手 / 一开就是好几门，最后都放弃了」
4. 「怎么判断一本书/一门课里哪些是重点」
5. 「我时间不多，怎么安排才能持续往前推」

### 语言信号
- "超前学习 / 提前学 / 学在前面 / 弯道超车"
- "帮我规划学习路线 / 先学什么后学什么"
- "这门课哪些是重点 / 怎么看出一门课的框架"
- "我想同时学好几门，怎么安排"
- "front-loading / study ahead / plan my learning path"

### 与相邻能力的区分
- 与 `material-pipeline`（AI 辅助备料）：本卡负责"决定学什么、学到多深、怎么排"；具体找哪本书、定哪些前置章节、怎么向 AI 提问，交备料卡。
- 与 `content-orchestration`（讲义编排）：本卡只管"规划 + 抓框架"；把内容真正排成一份能讲出去的讲义，交编排卡。
- 与 `ai-feynman-practice`（现有 skill）：本卡做规划与预习；"练到真懂、验收是否学会"交现有 skill。
- 与 `learning-loop`（总控）：本卡是总流程里"定目标"那一步的具体做法。

## E — 可执行步骤 (Execution)

0. **核验前提**（四项都基本满足再启动；缺哪项先说清）
   - 能在兼顾主业的情况下抽出时间精力
   - 会日拱一卒（把长期目标切成每天一小步）
   - 会费曼法（把学到的长期存住）
   - 有勇气独自啃超难知识
   - 完成标准：明确"可启动 / 需先补某一项"

1. **先保主业，再谈超前**
   - 把"重要且紧急"的有限游戏（学业、承诺的任务）**保质保量**做完，才谈超前
   - 完成标准：主业任务清单已明确，没有"主业六十分却去超前"的情况

2. **定范围：第一次只超前一门**
   - 只选一门课/一本书；能少不能多
   - 完成标准：范围写下来是**一个**具体对象，而不是"几门一起"

3. **定目标：热情强 + 可实现**
   - 目标要强到"起床就想做"，又必须现实可完成
   - 完成标准：目标可一句话说清，且能判断"做到什么算完成"

4. **抓框架**（不必全懂）
   - 读目录 → 读前言与每章开头 → 读各节首句 → 听课的话看第一节课
   - 完成标准：能画出一张"这门课大概讲什么、分几块"的骨架图

5. **定重点**
   - 数反复出现的名词/反复使用的方法；再看下游课程反复用到什么
   - 完成标准：列出若干"本课重点概念/方法"（数量视课程体量而定，无固定阈值）

6. **分层深度（漏斗）**
   - 明确：本门前置课要到 100%；当前超前这门先到 ~50%（框架+重点+基础）；再往后的层只求知道名字
   - 完成标准：给每一层标出目标深度，避免"要么全懂要么不碰"

7. **排日拱一卒计划**
   - 把"写完/学完一个区间"切成每天可执行的一小步
   - 完成标准：有一个每天可执行的动作 + 一个可验收的阶段终点

8. **定期纠偏**
   - 看不懂时先走**链条分析法**：顺依赖链往回找最前面没懂的那一环，补它
   - 真的不行：先自查 → 再看其他教材/Wiki → 换更简单的书 → 最后才考虑放弃
   - 完成标准：每次卡住都能定位到"是缺基础还是书不合适"，并给出对应动作

9. **验收（超前层的最低标准）**
   - ① 看出大致框架；② 看出重要方法；③ 学会最基础知识
   - 底线：若连最基础都看不懂（如抽代的群、实分析的勒贝格测度），可体面放弃——但放弃前把基础知识学会
   - 完成标准：三项都达到 → 这一层算超前完成，可把"上游"往上推一格

## B — 边界 (Boundary) ★

### 不要在以下情况使用此能力
- **有硬截止的应试阶段**：先把当前考试/主业保住，超前可能本末倒置
- **零基础、且当前课都没学好**：先补当前，别加新战线
- **已经严重超负荷/情绪接近崩溃**：作者明确警告"本已困难就别再创造困难"，否则心态崩溃、情绪能量溢出
- **要的是"从头系统学一门新学科"**：那是常规学习路径，不是超前学习

### 作者警告的失败模式
- **超前放弃**：目标过大、同时开六门坑 → 结果不是学会而是更早放弃（对应范围管理）
- **两头顾不过来**：主业六十分、超前书三个月 50 页、说不出学了啥 = 等于没看
- **只读前十页**：把"翻过"当"学过"；一本书前期知识密度极低，不学完一个区间等于白学
- **死守计划**：方向错了还不调整；或反过来频繁换书（灵活调整 ≠ 换来换去）
- **用"我基础差"自我放弃**：多数情况是链条上某一环没补上，不是天赋问题
- **把超前当碾压别人的工具**：作者强调目的是超越自己，否则会被攀比心态带偏

### 作者的盲点 / 局限
- **学科局限**：全部操作示例来自数学/理论学科；对实践型、技能型、非结构化知识领域是否适用，讲座未验证
- **起点偏差**：作者是多伦多大学数学博士在读，其"超前"的可行度对普通学习者可能被高估（幸存者偏差）
- **无来源的量化断言**："持续超前则 ≥80% 是在复习""六人平均水平"等为口述估计，无出处 → 待查证
- **未给对照证据**：整套方法建立在个人成功经验上，缺少"超前 vs 不超前"的对照数据

### 容易混淆的邻近方法论
- **预习**：跟着课程进度提前看 = 预习；自建进度提前学更难内容 = 超前。二者不是一回事
- **完美主义式学习**：漏斗结构恰恰反对"这门不学完不开下一门"
