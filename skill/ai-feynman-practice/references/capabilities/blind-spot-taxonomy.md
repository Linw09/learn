# 盲区清单四分类：把"没讲好"变成可补的账本

## R — 原文 (Reading)

> 等你讲完，让他把所有问题分成四类：事实错误、逻辑跳跃、术语空转、缺少边界条件，整理成一份盲区清单。
>
> — YouCore官方, 《费曼学习法最难的一步，被AI解决了》, 03:38-03:45

## I — 方法论骨架 (Interpretation)

复盘一次讲解/汇报/写作，说"讲得不好"没有用——把它变成一张**按四个互斥维度归档的盲区清单**才有用：

| 类别 | 含义 | 典型信号 | 补法方向 |
|---|---|---|---|
| 事实错误 | 说错了客观事实 | "记错了数据/张冠李戴" | 查证事实来源 |
| 逻辑跳跃 | 推理缺步或不通 | "A 直接跳到 C，问为什么就卡" | 补全推理链条 |
| 术语空转 | 用了术语却讲不清其含义与成立条件 | "能说出'熵'但翻译不成大白话" | 把术语翻译到生活例子 |
| 缺少边界条件 | 没交代结论在什么范围内成立 | "没说这方法什么时候失效" | 补适用前提与反例 |

判据示例：术语能否**当场翻译成大白话**，不能即"术语空转"——这是四类里最隐蔽也最常见的漏洞（用术语掩盖没懂）。

**为什么有用**：① 把模糊的"没讲好"结构化，每类补法不同；② 清单是练习的**输出物**（不是附属笔记），是下一轮与最终验收要**清空**的对象（对应 `mastery-acceptance` 的第一条）。

## A1 — 书中的应用 (Past Application)

### 案例：三档陪练的产出物即盲区清单
- **问题**: 苏格拉底档追问暴露一堆问题，零散记不住
- **方法论的使用**: 作者规定讲完后 AI "把所有问题分成四类……整理成一份盲区清单"
- **结论**: 毒舌档继续把含糊处写进同一份清单；最终以"清单为空"作为过关条件之一
- **结果**: 盲区清单成为贯穿练习与验收的核心数据结构

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力?

1. 复盘讲砸的分享/汇报/答辩：「讲得不好，但不知道差在哪」
2. 三档陪练产出归类（配合 `three-tier-drill`）
3. 写文章/方案被批"不清楚"，想定位问题
4. 系统整理自己的知识漏洞

### 语言信号

- "复盘一下我刚才讲的 / 帮我看看哪里没讲好"
- "讲得烂但说不出哪烂"
- "把我的问题归类一下"
- "盲区清单 / 术语空转 / 逻辑跳跃是什么意思"
- "review my explanation / where did I go wrong / categorize my mistakes"

### 与相邻能力的区分

- 与 `three-tier-drill`：本卡是**分类格式/账本**，三档陪练的产出物就是它；也可脱离陪练单独用于任何复盘
- 与 `understanding-diagnosis`：诊断卡负责"找出讲不清的地方"，本卡负责"给这些地方分类归档"——诊断完接本卡分类

## E — 可执行步骤 (Execution)

1. **收集问题**：把一次讲解/练习中暴露的所有卡壳、被问倒、含糊处列出来
   - 完成标准：≥1 条具体问题（"讲得不好"不算，要能指到某句话/某个点）

2. **逐条四分类**：对照四类判据归档——说错事实？推理跳步？术语讲不清？没交代边界？
   - 完成标准：每条问题归入恰好一类；不确定的用判据测（如"这个词能翻译成大白话吗"）

3. **输出盲区清单**：整理成结构化清单（类别 + 问题 + 涉及概念 + 状态：待补/已补）
   - 完成标准：清单可直接用于补漏与验收；每个"事实类"条目标注"待人工查证"

4. **进入补漏或验收**：把清单交给用户补漏（查资料/重新学），补完用 `mastery-acceptance` 判定清零
   - 完成标准：清单条目逐条有去向（已补/转练习/确认非漏洞）
   - 判停点：用户只要复盘归因 → 完成第 3 步即可

## B — 边界 (Boundary) ★

### 不要在以下情况使用此能力

- 问题是**表达风格/情绪/内容素材不足**（不是理解漏洞——没料是"没内容"不是"讲不清"）
- 用户要的是改进演讲台风/口才（四类只覆盖理解层面）

### 作者警告的失败模式

- **术语空转（g07）**是四类中唯一作者自造的、专门抓"用术语掩盖没懂"的类——别把"术语多"当专业，翻译不成大白话就是空转
- 清单≠错题本：它记的是"理解漏洞的分类账"且是**验收对象**，不是记下就完事的笔记
- 事实类条目不能靠 AI 判"对/错"就划掉（见 `ai-guardrails` 护栏③与 ce08）——必须人工查证

### 作者的盲点 / 局限

- 四分类对"概念混淆类"盲区（把两个相似概念当成一个）覆盖不足——此类会落入"逻辑跳跃"或"术语空转"边缘，归类时需留意
- 清单有效性依赖提问质量：AI/听众问不到真盲区时，清单会"假空"
