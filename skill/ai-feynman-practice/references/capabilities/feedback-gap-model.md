# 反馈断点模型：费曼法瓶颈的机制重述

## R — 原文 (Reading)

> 费曼学习法通常分为四步：先选一个概念，再讲给别人听，然后发现讲不清的地方，最后回去补漏再简化。第二步到第三步之间必须穿过一个反馈断点。这个断点需要两个条件同时存在：一个愿意听的听众，一个敢指出问题的反馈。可现实里这两样经常凑不齐。
>
> 很多人以为费曼学习法难在讲，其实讲只是动作。真正难的是讲完之后，有没有人把你拽回真实理解。
>
> — YouCore官方, 《费曼学习法最难的一步，被AI解决了》, 01:14-01:51

## I — 方法论骨架 (Interpretation)

费曼学习法是一个四步闭环：**选概念 → 讲给别人听 → 发现讲不清 → 回去补漏再简化**。作者的关键洞察是：这个流程真正卡住的不是"讲"这个动作，而是第二步到第三步之间必须穿过的一道**反馈断点**——从"讲了"到"发现自己没懂"的转化，需要两个资源**同时在场**：

① 一个**愿意听的听众**（肯花时间听你完整讲完）；
② 一个**敢指出问题的反馈**（听完敢挑错，而不是客气点头）。

现实里两者常凑不齐：不好意思总打扰别人（听众稀缺）、身边人发现问题也不好意思追问（反馈稀缺）、大脑还会**打圆场**替你把漏洞盖过去。于是第四步补漏永远等不到触发，闭环原地打转——学习者以为"我做完费曼法了"，其实只做完了第一步。

**通用归因框架**：当一个流程"每一步都做了却没进展"，别只盯着动作本身，要检查动作之间那道**转化门槛**缺了什么资源——这类缺口通常是"反馈/校验"型资源，靠加动作堆量补不上。

## A1 — 书中的应用 (Past Application)

### 案例：作者本人的"闭环空转"与"闭环闭合"
- **问题**: 看科普视频"觉得彻底懂了"，是不是完成了学习
- **方法论的使用**: 作者把"懂了的感觉"放进四步闭环检验——讲给太太（第 2 步）→ 等反馈
- **结论**: 太太的两个追问（玻璃碗/金属勺）就是那道反馈断点；没有她，作者会带着"我懂了"的错觉停在原地
- **结果**: 断点被穿过，作者才发现自己卡在"讲不清"，闭环从"假完成"变成"真暴露"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力?

1. 学习/练习长期没进展：「看了很多教程还是不会」
2. 练习"走形式"：「我费曼法也做了呀，怎么没用」
3. 复盘流程：「这个环节明明都做了，为什么转不动」
4. 反馈资源稀缺：「找不到人给我反馈怎么办」

### 语言信号

- "学了很久没长进 / 感觉在原地打转"
- "费曼法我试了没用"
- "看了很多教程，一用就废"
- "为什么我的学习闭环没转起来"
- "learning stuck / no progress despite studying / feedback loop broken"

### 与相邻能力的区分

- 与 `three-tier-drill`：本卡是**诊断/归因**（你卡在哪、缺什么）；三档陪练是**处方**（用 AI 补上断点练起来）。用户问"为什么学不会"走本卡归因后转三档。
- 与 `anti-rationalization`：打圆场是断点过不去的一个内在成因；本卡讲整个断点的结构（听众+反馈双资源），打圆场卡讲"自我感觉为什么不可信"。

## E — 可执行步骤 (Execution)

1. **定位用户卡住的环节**：对照费曼四步（或用户自己的学习流程），问清"动作做到哪一步了、之后发生了什么"
   - 完成标准：明确卡点是"没输出（没讲/没做题）"还是"输出了但没人纠错"

2. **检查断点双条件**：问两个问题——有没有人完整听完你的输出？听完后有没有人指出过具体错误？
   - 完成标准：判定缺口类型：无听众 / 有听众无敢错反馈 / 有外部反馈但被自己打圆场过滤（转 `anti-rationalization`）

3. **指出资源缺口而非动作缺口**：告知用户——卡住的不是"讲得不够多"，是转化门槛缺反馈资源；靠继续看教程（堆输入）补不上
   - 完成标准：用户理解"缺的是反馈源"，而非误以为要"更努力地学"

4. **给出补位路径**：引入外部反馈源（真人教练/同伴互评）或 AI 替代（转 `role-decomposition` + `ai-guardrails` 搭建，或直接用 `three-tier-drill`）
   - 完成标准：用户拿到一个可执行的补位方案

## B — 边界 (Boundary) ★

### 不要在以下情况使用此能力

- 用户是**纯粹动力/习惯问题**（缺的不是反馈，是开始做）
- 用户卡在"不懂该学什么/方向不清"（那是选题与规划问题，不是反馈断点）
- 零基础领域（还没到"有输出等反馈"的阶段）

### 作者警告的失败模式

- **把"讲"当完成（ce04）**：讲完即收工 = 四步只做了第一步；断点没穿过，方法退化成复述
- **反馈结构性稀缺（ce02）**：身边没人愿听/敢错是常态结构，不是你不努力——需要找替代反馈源，而不是自责
- **打圆场（ce03）**：大脑会用"只是没组织好语言"把断点伪装成已通过

### 作者的盲点 / 局限

- 视频把断点缺失归为方法失效主因，但未讨论"学习者确实讲不清而无人能补"的知识深度问题——断点补上后仍需学习能力本身
- "AI 能补上"的论断建立在当前模型能力上，模型问不到真盲区时断点只是"形式补上"
