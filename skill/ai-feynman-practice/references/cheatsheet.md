# 决策规则速查 — 《费曼学习法最难的一步，被AI解决了》(B 站短视频)

| 能力 | 一句话规则 |
|---|---|
| 输出测试判定法：看懂≠能讲清楚 | 别问"我懂了吗"，把概念不看资料讲一遍，卡壳处即没懂。 |
| 反馈断点模型：学不会的瓶颈归因 | 方法卡住别盯动作，检查动作之间那道"转化门槛"缺了什么资源。 |
| 防打圆场：自我感觉型检测不可信 | 卡壳时若心里冒出"我只是没组织好语言"，把这句话当成没懂的证据。 |
| 知识清晰度归因：差距在讲得清，不在记得多 | 补学习先补"讲不清"的部分，别继续堆"知道但讲不出"的新知识。 |
| 缺搭子时按角色拆需求再找替代 | 缺理想搭档时，先列出你需要对方扮演的 N 个功能角色，再逐项找替代品。 |
| AI 三条护栏：把不可信反馈源改造成陪练 | 每条护栏精确对应一个 AI 失败模式——锚定上一句、没讲清不许解释、外部事实只标待查证。 |
| AI 费曼三档陪练协议(核心执行器) | 一档把 AI 当 12 岁小孩讲流畅，二档让它逐段追问挖盲区，三档让它拆台验收，直到清单清零。 |
| 盲区补漏闭环(把练出来的坑真正填上) | 挖出的坑要填：显式开"补漏窗口"让 AI 从考官切讲解员，一次只补一条；补完切回考官重讲该条，不卡壳才算补上（事实类仍须人工查证）。 |
| 盲区清单四分类(理解漏洞诊断账本) | 复盘别只说"讲得烂"——按事实错误/逻辑跳跃/术语空转/缺边界条件四类归档。 |
| "真懂"验收标准(清单一度清零怎么算通过) | 过关不看"感觉讲顺了"——盲区清单清零 + 隔 10 分钟复测仍空 + 30 秒讲清 + 扛追问（含反例/边界/近邻/**迁移**四类探测）+ 独立度达标（核心节点不是被 AI 代答的）。 |
| AI 定位框架：工具搭检验场，不替你理解 | AI 越能替你解释总结，你的假懂越深——它只该搭检验场。 |
| 把暴露漏洞重释为检测成功(挖坑即战绩) | 练习价值以挖出多少真坑计，不以讲得顺不顺计；被问倒不是失败，是检测做对了。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
