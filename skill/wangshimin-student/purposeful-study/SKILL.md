# 功利性学习

## 触发与不触发

**适用**：你要学的东西指向一个具体问题或任务，需要决定学什么、学多少、怎么用。比如下周考试、下周要交的作品、下周社团要做招新海报。

**不适用**（以下 4 条为全 pack 共识）：
- 考试应试技巧（押题、刷题策略、答题套路）——本方法不管。
- 记忆与遗忘管理（艾宾浩斯、间隔重复、记忆宫殿）——本方法不教怎么记住。
- 时间管理与日程安排——学到几点、每天学几小时，本方法不管。
- 小组协作与分工——谁负责哪块，本方法不管。

## 核心原则

1. 学习从真实问题出发，不从书的目录第一页出发。
2. 选一个正在攻克的真问题，别选"把整本书学完"。
3. 时间紧就只学马上能用的，压住想多学一点的冲动。
4. 第一次用方法要严格照做，别自己先删改。
5. 复杂内容先抓主干跑通，再一条条加条件。
6. 跑通的流程做成模板，下次直接复制，用完再补经验。

**失败史（本书少有的真实记录）**：作者 2015 年第一版课程在学员身上失败过。学员要么信心受挫，要么生搬硬套。第二版重做后才成功。对学生这样说：照着方法学没效果，不一定是方法错，可能是你第一次就没照做。先严格做一遍，再判断它行不行。

**一句提醒**：原书用"基底神经节大象、骑象人、1 小时遗忘"讲大脑。⚠️原书用流行心理学隐喻，非机制，此处不展开。

**学生案例**：下周要交物理实验报告，别从第一章"力与运动"顺学。先定问题是"写不出误差分析"，再只学误差分析那一节，当晚就用它改报告。跑通后把步骤做成清单，下次做化学实验直接套。

## 执行步骤

1. **选问题**
   挑一个你正在攻克的真实问题，写下来。
   完成标准：能用一句话说清卡在哪，且这个问题本周就要解决。

2. **定范围**
   按考试或任务的截止时间决定学多少。
   完成标准：列出必须学的最少内容，并把可以缓学的划掉。

3. **实际用**
   拿学到的东西去解决第 1 步那个问题。
   完成标准：第一次严格照步骤做，不跳步、不删改。

4. **最简应用**
   先抓主干，在最简单条件下跑通。
   完成标准：能拿出一个最小可用的结果。

5. **逐条加条件**
   主干跑通后，再一条条加回复杂条件。
   完成标准：每加一条都能跑通，跑不通就退回上一步。

6. **自然重复**
   把跑通的流程写成模板或清单。
   完成标准：下次同类任务能直接套用，用完把新经验补回模板。

## 判断标准

| 判断 | 表现 | 结论 |
|---|---|---|
| ok | 能说清这个知识点解决哪个问题 | 做对了 |
| ok | 第一次完全照步骤做，没跳步 | 做对了 |
| warn | 列了一长串"要学的"，没划掉任何一条 | 范围没收住 |
| warn | 学了三天还没拿它解决任何问题 | 停在"学"没到"用" |
| warn | 方法没用就说方法不行，却没严格做过一遍 | 先补做一遍再评价 |

## 与相邻能力的区分

- 与 `skill-three-types`：本能力决定**学什么范围**，它决定**用什么路径学**。
- 与 `fast-reading`：本能力是**学习决策**（学哪些、学到什么程度），它是**输入方式**（怎么把材料读进来）。
- 与 `problem-framing`：问题还没界定清楚时先用它，别急着定学习范围。
- 与 `framework-topdown`：需要现成框架拆问题时用它，本能力不提供框架。
- 与 `hypothesis-testing`：时间信息不足时用它先猜后验，本能力仍管范围。
- 与 `problem-five-step`：它是问题解决的全程调度，本能力的"选问题"是它的第一步。
- 与 `visualize-content`：要输出一张图时用它，本能力只决定学什么。

## 边界

- 本方法来自面向成人的读物，学生场景为改写。
- 答不了四类场景：应试技巧、记忆管理、时间管理、小组协作。遇到要说"这套方法解决不了你的问题"。
- 本能力不教怎么记住内容，记不住该找记忆类方法。
- 不负责排学习日程，只负责定范围和用法。
