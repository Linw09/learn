# 快速阅读

## 触发与不触发

**适用**：手上有教材、考纲、参考书、科普书这类长材料，时间有限，只需要从中拿到一部分。

**不适用**：
- 考试应试技巧——本能力不押题、不给答题套路。
- **记忆与遗忘管理**——本能力只教怎么快速取信息，不教怎么记住。
- 时间管理与日程安排——什么时候读、读几天，本能力不管。
- 小组协作与分工——谁读哪段，本能力不管。

## 核心原则

1. 读之前先定目的，不知道要什么就别开始翻。
2. 只拿你需要的那部分，不追求把整本读完。
3. 整体阅读只要 1-3 个有用信息，多了就失控。
4. 关键词句最多留 16 个，超了就删或换。
5. 多重阅读要变速：不相关的跳过，熟悉的快扫。
6. 只教你限定时间内拿到需要的部分，不教怎么记住。

## 执行步骤

### A. 整体阅读五步（只想要 1-3 个有用信息）

1. **定目的**：写清解决什么问题、解决到什么程度。
   完成标准：能用一句话说出你要找什么。
2. **提出具体问题**：把目的转成向材料的具体提问。
   完成标准：问题不带"怎么变厉害"这类模糊说法。
3. **选关键词句**：边翻边圈，最多 16 个。
   完成标准：翻页速度以看清每页为准，超 16 个就删或换。
4. **挑三个关键点**：直接选三个核心，或把关键词归类成三组。
   完成标准：三个点能覆盖材料主干。
5. **归纳成一句话结论**：用自己的话写一句结论。
   完成标准：一句话说清这份材料的要点。

### B. 多重阅读四步（要系统学一份材料）

1. **明确目的**：说清这次要知道什么、到什么深度。
   完成标准：目的能写成一句话。
2. **画出框架**：先翻目录、标题、图表，画出整体结构。
   完成标准：能画出一张层级图。
3. **变速阅读**：按熟悉程度分配速度。
   完成标准：不相关的跳过；熟悉的最快扫；不熟的正常读且每章停下回忆；难的标记后略读。
4. **重点精读并归入自己的知识体系**：把重点放进你已有的结构里。
   完成标准：**不照抄材料的顺序**，按自己的结构重排。

### C. 主题阅读两步（围绕一个主题读多份材料）

1. **先搭主题框架**：为这个主题列出一张提纲。
   完成标准：提纲能覆盖你想搞清的几块。
2. **按图索骥填材料**：带着提纲去各份材料找对应内容。
   完成标准：每块提纲都填上了材料。

⚠️原书标题"一天读上百份资料"为夸大表述，此处不保留该量化承诺。

**学生案例**：读教材先翻目录和图表定框架，只精读考纲点到的那几节；读科普书只为搞清一个概念，用整体阅读五步拿到三点就走。

## 判断标准

| 判断 | 表现 | 结论 |
|---|---|---|
| ok | 读之前先写下目的和问题 | 做对了 |
| ok | 关键词句控制在 16 个内 | 做对了 |
| warn | 从头到尾逐字读完，却说不出要点 | 没定目的 |
| warn | 关键词圈了一整页 | 没做取舍 |
| warn | 读完还是记不住，就想换个记忆方法 | 用错了能力 |

## 与相邻能力的区分

- 与 `purposeful-study`：本能力是**输入方式**（怎么读进来），它决定**学什么范围**。
- 与 `skill-three-types`：本能力管读材料，它管判断技能类别和入门路径。
- 与 `problem-framing`：问题没界定清楚时先用它，读之前也要先弄清要什么。
- 与 `framework-topdown`：多重阅读"画框架"可借它，但拆解问题归它。
- 与 `hypothesis-testing`：时间不足先猜后验归它，本能力只管取信息。
- 与 `problem-five-step`：它是问题解决的全程调度，本能力不参与调度。
- 与 `visualize-content`：要把读到的内容画成图归它，本能力到"一句话结论"为止。

## 边界

- 本方法来自面向成人的读物，原书案例是读商业类书，此处已换成课本与科普书。
- 答不了四类场景：应试技巧、记忆管理、时间管理、小组协作。
- **本能力不教怎么记住内容**，记忆管理不在范围内。
- 只保证限定时间内拿到需要的部分，不保证读全读懂。
