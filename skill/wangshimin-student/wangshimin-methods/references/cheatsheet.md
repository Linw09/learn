# 速查表 — 《思维力》《学习力》学生版

> 只给结论；需要原文依据、例子或反例时读对应能力卡。

## 8 个 skill 速查

| 能力 | 什么时候用 | 一句话核心 |
|---|---|---|
| problem-five-step | 事情想不清楚、不知从哪下手 | 界定问题 → 构建框架 → 明晰关键 → 高效执行 → 检查调整。 |
| problem-framing | 只想把"问题到底是什么"弄准 | 先分清四类界定不清，用 5W2H、5Why、隐含假设把问题说实。 |
| framework-topdown | 有现成框架可用、想快速拆解 | 选框架 → 分解问题 → 多维思考 → 检查框架（只查不重）。 |
| hypothesis-testing | 时间不够、信息不全 | 先猜再验：创建假设 → 明晰关键 → QDT 粗验 → 快速调整。 |
| visualize-content | 把想清楚的内容画成图 | 构建表达框架 → 选择图表结构 → 按 5W2H 填充元素。 |
| purposeful-study | 决定学什么、学多少、从哪切 | 选问题 → 定范围 → 实际用；先最简应用再自然重复。 |
| skill-three-types | 判断学的属于哪类技能 | 分程序性认知 / 理解性认知 / 行为技能，各走各的路径。 |
| fast-reading | 限定时间从一本书里取所需 | 先定目的再取信息；整体阅读取 1-3 点，多重阅读系统吸收。 |
