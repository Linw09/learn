# 形象化表达三步：把想清楚的内容变成一张图

## R — 原文 (Reading)

原书认为只靠文字只激活逻辑思维，加上图才能把形象思维也调动起来。
> "再加上图形的形象化表达，形象思维也会被激活"（P205-234）

理论依据（左右脑、格式塔）本卡只保留这一句，不展开，因为学生用不到。

## I — 解释 (Interpretation)

三步：
1. 构建表达框架——先想清楚结论和支撑点，再决定画什么。
2. 选择图表结构——按要表达的关系挑一种图。
3. 填充元素——把内容按 5W2H 归位。

学生图表库：时间轴、对比表、流程图、结构树、因果图、思维导图、坐标图、数据图表（柱 / 折 / 饼）。
填充对应：What / Who → 几何图形或图标；Why → 因果图；When → 时间轴；How → 流程图；Where → 地图或区域图；How much → 柱 / 折 / 饼。

## A1 — 书中的例子 (Past Application)

### 案例 1：读书笔记
- ⚠️原书案例为职场语境，此处改写。
- 问题：读了一章科普书，笔记抄了一整页文字。
- 用法：先用结构树搭出"主题—三个分支—例子"。
- 结论：图上来回一看就懂，比抄原文省时。

### 案例 2：班级展示
- 问题：介绍一次活动，讲稿全是流水账。
- 用法：选时间轴，把活动按先后节点排开。
- 结论：听众顺着时间轴就能跟上。

### 案例 3：实验报告配图
- 问题：实验数据列成表格，看不出趋势。
- 用法：How much 用柱图或折线图表示。
- 结论：换成图后趋势一眼可见。

## A2 — 什么时候用 (Future Trigger)

### 用户会在什么情境下需要
1. 要把想清楚的内容讲给别人，或做成一份展示。
2. 笔记、报告、作业需要配图。
3. 数据或关系用文字说不清。

### 语言信号
- "怎么画 / 用什么图 / 画个图说"
- "做成思维导图 / 流程图 / 时间轴"
- "这张图怎么摆"

### 与相邻能力的区分
- 与 problem-five-step：内容还没想清楚时先转 problem-five-step。
- 与 framework-topdown：后者是拆解问题的框架，本卡是把结果画出来。

## E — 可执行步骤 (Execution)

1. 构建表达框架
   - 完成标准：先写出一句话结论，再列出支撑它的 2-4 个要点。
2. 选择图表结构
   - 完成标准：从图表库里挑一种，能说出它对应哪个要点关系。
3. 填充元素
   - 完成标准：按 5W2H 归位——What / Who 用图形图标、Why 用因果图、When 用时间轴、How 用流程图、Where 用地图、How much 用柱 / 折 / 饼。
4. 自查
   - 完成标准：遮住文字只看图，还能读出结论。

## B — 边界 (Boundary)

### 原书边界
- 原书图表偏商务场景，本卡已换成学生能用的图表库。
- 图是表达手段，不能代替把内容想清楚。

### 这套方法答不了的四类学生场景
- 考试应试技巧：押题、刷题策略、答题套路。
- 记忆与遗忘管理：艾宾浩斯、间隔重复、记忆宫殿。
- 时间管理与日程安排。
- 小组协作与分工。
遇到以上场景，明说"这套方法解决不了你的问题"，不要硬套。
