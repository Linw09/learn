# 假设思考

## 触发与不触发

**适用**：时间不够时，先下结论再验证，用粗略测试快速逼近答案。适合高中以上。初中只用 QDT 那一步。本方法是五步法的加速版。

**不适用**：考试应试技巧（押题、刷题策略、答题套路）；记忆与遗忘管理（艾宾浩斯、间隔重复、记忆宫殿）；时间管理与日程安排；小组协作与分工。这四类问题本方法答不了。

## 核心原则

1. 五步法是顺向，问题走到结论；假设思考是倒着，结论倒推问题。
2. 时间信息充足用五步法，不足才用假设思考。
3. 创建假设不是拍脑袋，是"有框架地蒙"：先用框架框定范围再提假设。
4. QDT 是粗略验证：几分钟内凭现有判断假设成不成立。
5. 全面验证有三条路：试验主导、讨论主导、分析主导。

## 执行步骤

1. **界定问题**
   - 完成标准：能用一句话写清要判断的是什么，并知道时间紧在哪。
2. **创建假设**
   - 完成标准：先用框架框定范围，再给出一个明确结论型假设。
3. **明晰关键**
   - 完成标准：找出验证这个假设最关键的一两个点。
4. **验证假设**
   - 完成标准：先用 QDT 快速判一下；必要时走试验、讨论、分析之一做全面验证。
5. **快速调整**
   - 完成标准：假设不成立就立刻改，能说出改后的新假设。

## 判断标准

| 状态 | 表现 |
|---|---|
| ok | 假设先有框架框范围，不是凭空猜 |
| ok | 先 QDT 再决定要不要全面验证 |
| ok | 讨论验证时，参与的人真的懂这件事 |
| warn | 直接拍脑袋下结论，没有框架 |
| warn | 时间明明充足，还硬用粗略测试 |
| warn | 找不懂的人讨论，验证流于形式 |

## 与相邻能力的区分

- 与 `problem-five-step`：本 skill 是它在时间信息不足时的加速版；充足时用完整版。
- 与 `problem-framing`：本 skill 假定问题已大致清楚；连问题都没界定清楚转 `problem-framing`。
- 与 `framework-topdown`：本 skill 借框架来框定假设范围；只想顺向拆解问题转 `framework-topdown`。
- 与 `visualize-content`：本 skill 属分析侧，负责下判断；要画图转 `visualize-content`。
- 与 `purposeful-study`：本 skill 解决怎么快速判；该学什么转 `purposeful-study`。
- 与 `skill-three-types`：判断技能类型与入门路径转 `skill-three-types`。
- 与 `fast-reading`：限定时间从书里取信息转 `fast-reading`。
- 与 `wangshimin-methods`：问两本书本身或未晋级主题，转路由入口。

## 边界

- 本方法来自职场读物，原书案例是职场语境，学生版已改写。
- 考试应试、记忆管理、时间管理、小组协作四类问题答不了。
- "有框架地蒙"对初中生偏重，初中只用 QDT。
- ⚠️QDT 全称 Quick and Dirty Test，原书未给出处。
- ⚠️讨论主导验证要求参与者懂这件事，找不到懂的人就别走这条路。
