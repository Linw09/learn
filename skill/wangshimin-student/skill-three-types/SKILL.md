# 三类技能与入门路径

## 触发与不触发

**适用**：准备学一门新技能或新学科，需要先判断它属于哪一类，再决定先理解还是先练、有没有框架可套。

**不适用**：
- 考试应试技巧——本能力不押题、不给答题套路。
- 记忆与遗忘管理——怎么记住不在本能力范围。
- 时间管理与日程安排——每天练多久、排到哪几天，本能力不管。
- 小组协作与分工——谁练哪块，本能力不管。

## 核心原则

1. 先判断技能类别，再选路径，别拿一种路径套所有技能。
2. 程序性认知技能：先理解再练熟练度，练不够就是不会。
3. 理解性认知技能：先挑框架，第一次严格照框架走，再质疑改进。
4. 行为技能：先看别人怎么做，再量力模仿、分解、局部细化。
5. 跨学科入门不换领域，是换学科，别硬套原学科那套方法。
6. 别把自己当白纸，旧知识能迁移；也别贪大求全想一次学完。

## 执行步骤

### A. 程序性认知技能（编程、Excel、乐器操作、书法基础）

先理解再练熟练度。

1. **基本了解**：弄懂它大概做什么、几个基本名词。
   完成标准：能用三句话说清它是干嘛的。
2. **简单入门**：跑通一个最小的例子。
   完成标准：亲手做出一个能看的结果。
3. **迭代深化**：每次只加一个新功能或新动作。
   完成标准：每轮都能独立跑通再进下一轮。
4. **自然重复**：把常用操作做成笔记或模板。
   完成标准：下次能直接复用，不用重查。

### B. 理解性认知技能（历史因果、科学概念、文学分析、经济学）

概念为主、讲规律。

1. **挑框架**：找一套现成的分析框架（时间线、因果链、对比表）。
   完成标准：选定一套框架，能说出它管哪几件事。
2. **第一次严格照框架用**：选一个具体材料，一步步套框架走。
   完成标准：严格照框架做完，不跳步。
3. **质疑改进**：做完再问框架哪里不顺手，需要加什么。
   完成标准：能指出框架的一处不足，并补一条自己的规则。

### C. 行为技能（游泳、跳绳、投篮、体能）

身体熟练度。

1. **挑对象**：找到一个做得好的示范者或视频。
   完成标准：能反复看清对方每个动作。
2. **量力模仿**：按自己当前水平模仿，不求一步到位。
   完成标准：能做出大致动作轮廓。
3. **分解简化**：把整套拆成几个小动作分别练。
   完成标准：每个小动作单独能完成。
4. **局部细化**：再逐个小动作抠细节。
   完成标准：合起来比上一轮更稳。

### D. 跨学科入门五步

> **改名说明**：原书叫"切入新行业五步法"，面向成人换工作。学生不换工作，是换学科，故此处改名为**跨学科入门**。

三个陷阱先避开：

- **硬套别的学科的方法**：文科生用背年代那套去学统计。
- **把自己当白纸**："我没学过这个"，其实旧知识能迁移。
- **贪大求全**：想一次把这门学科从头学完。

五步：

1. **构建框架**：先找出这门学科的整体骨架。
   完成标准：能画出它的主要分支。
2. **比对迁移**：拿你熟的知识去对照，找相同与不同。
   完成标准：写出至少两条能迁移的经验。
3. **功利取舍**：只先学当前任务要用的那部分。
   完成标准：列出必学清单并划掉可缓学的。
4. **整体应用**：用学到的部分解决一个真实问题。
   完成标准：做出一件能拿出手的结果。
5. **改进迭代**：用后补缺，再学下一块。
   完成标准：每轮都比上一轮多解决一个问题。

**学生案例**：文科生跨到统计，先把"描述—推断"当骨架，再把背时间线那套改成按例题记公式；物理生跨到编程，把物理实验的"设条件—看结果"迁移到调试代码。

## 判断标准

| 判断 | 表现 | 结论 |
|---|---|---|
| ok | 先说出技能类别，再选路径 | 做对了 |
| ok | 第一次严格照框架或步骤走 | 做对了 |
| warn | 拿背概念的方式去练乐器 | 类别判断错了 |
| warn | 说"我没学过"，不肯迁移旧知识 | 掉进白纸陷阱 |
| warn | 一上来就要学完整门学科 | 掉进贪大求全 |

## 与相邻能力的区分

- 与 `purposeful-study`：本能力决定**用什么路径学**，它决定**学什么范围**。
- 与 `fast-reading`：本能力管怎么学会，它是把材料读进来的方式。
- 与 `framework-topdown`：需要拆一个具体问题时用它；本能力只在"选学科框架"时借框架。
- 与 `problem-framing`：问题没界定清楚先用它，别急着选入门路径。
- 与 `hypothesis-testing`：它管时间不足时的加速验证，本能力管入门路径。
- 与 `problem-five-step`：它是问题解决的全程调度，本能力只做学习分派。
- 与 `visualize-content`：要输出一张图时用它，本能力不画图。

## 边界

- 本方法来自面向成人的读物，学生场景为改写。
- 答不了四类场景：应试技巧、记忆管理、时间管理、小组协作。
- 本能力只判断类别和给路径，不教具体学科知识。
- 一类技能可能同时沾两类，选占比大的那类走。
