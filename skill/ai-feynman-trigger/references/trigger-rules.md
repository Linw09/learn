# 触发规则 — 什么时候发起检验

## 五条规则

| | 触发 | 证据在哪 | 可靠性 |
|---|---|---|---|
| R1 | 用砸了：依赖的说法在现实里不成立 | 现实结果 | 高 |
| R2 | 被纠正：别人把它指出来了 | 别人 | 高 |
| R3 | **「我早就懂了」，且后面跟着一个具体的东西** | 用户说的 | 中 |
| R4 | 输出：要把这个讲给别人或写下来 | 产出物 | 中 |
| R5 | 决策：用这个说法做取舍，且取舍有代价 | 决策记录 | 中 |

R1/R2 证据在体外，逃不掉。R3/R4/R5 证据在用户手里 —— 但**只有「感知」在用户手里，「裁决」不在**（见下）。

## R3 是本 skill 存在理由的直接回答

原问题是「我不知道自己不懂，所以永远不会去检验」。R3 的答案是：

**「我早就懂了」这句话本身，就是触发器。** 你不需要先承认自己不懂，你只需要承认你说了这句话。

三个别的信号都比不上的优点：

1. **出现得最准** —— 只在真实理解的薄弱区最强，不在真懂的地方浪费时间
2. **不需要承认任何事** —— 触发动作是「持有信心」，不是「承认无知」。后者需要意愿，前者不需要
3. **自带正反馈** —— 说出「我早就懂了」很舒服，顺手检验 30 秒不构成负担

**限定的必要性**：「我早就懂了」后面必须跟着一个**具体的东西**（一个决策 / 一段要写的东西 / 一个要答的问题）。

不加限定会退化成口头禅 —— 一天说二十次。**限定之后触发条件自己就带上了真实场景**，不需要额外节流机制，也不算收窄：真正让你说出这句话的时刻，本来就总是在某个具体麻烦的前面。

## 通道优先级

触发不只靠用户开口。按证据来源分五层：

```
1. 他人已经指出的→ 零成本，必查
2. 卷面/成绩痕迹              → 零成本，自动
3. 举证式提问                → 30 秒，主动
4. 变式重做（测「蒙对」）       → 60 秒，自动
5. 输出/决策前                → 强制，此时假阳性可接受
```

**前两层不需要用户承认任何东西。**

### 第 2 层：卷面痕迹

| 痕迹 | 说明 |
|---|---|
| 答案对，过程是空的 | 结果对但没路径 —— 认得的特征 |
| 蒙对 | 变一个数立刻失效 |
| 会做但跳过步骤 | 熟练掩盖了断裂 |
| 成绩稳定但不上去 | 粗心不会稳定 |
| 同类题反复错但不同题都对 | 知识有洞的典型指纹 |

**「蒙对」最强**：把题里的数字换掉重做一次。行为变了，结论就出来了。整个检测没有一句提问问到他。

### 第 3 层：举证式提问

**提问在语法上不给借口留插槽。**

|不要问 | 要问 |
|---|---|
| 你懂吗？ | 用一句话说出来 |
| 为什么错了？ | 换个条件还成立吗 |
| 是不是粗心？ | 凭什么 |

**「粗心」回答不了「用一句话说出来」。** 这是结构性防御 —— 拦话术要识别，提问形式不用识别。

## 核心概念触发（节拍器）

**每学一章的核心概念 → 默认检验一次。** 不是可选，是学习流程的标准环节。

> 类比：不是你觉得不舒服才体检。

**为什么这条最重要**：把触发时机从**事后**（失败后）移到**学的时候**。事后触发时洞已定型，补起来贵；学的时候洞最大，也最便宜。

**「核心概念」的可执行判据**：**在材料里有可指认位置**的知识点。

- 算：课本里的定义、法则、公式的来源、每章第一节的核心概念
- 不算：具体数值、已经熟练的计算、要求「理解」的整章内容

**节拍器外部且现成**：课本章节自带节拍。**不用编 7 天/30 天这种没有依据的数字**，也不用维护台账。

## 感知与裁决必须分开

这是整个调度层唯一真正重要的结构。

| | 归属 | 为什么 |
|---|---|---|
| **感知**（发生了什么） | 用户 | 客观监测需要 harness，个人场景没有 |
| **裁决**（要不要检验 / 懂到什么程度 / 算不算通过） | 必须外部 | 一切依赖本人感觉的判定必被打圆场污染 |

所以规则写成这个形状：

> 用户只报告**发生了什么**。
> 用户从不报告**要不要检验**、**懂到什么程度**。

绝大多数失败的自我检验机制，都是因为把两者混在一个动作里 —— 人报告事实的同时，顺手把结论也报了。

**残留（必须诚实说明）**：R3/R4/R5 靠用户不漏报。R1/R2 漏报不了（失败已发生、纠正已发生），所以可靠性最高。

若三个月后回看发现 R3 一次都没触发过，说明这条规则没活下来 —— 该动的是触发条件，不是加台账。

## 两条不能省的规则

### 一、不给借口留插槽

拦截靠提问形式，不靠识别。见上表。

### 二、强制发起，不降低门槛

**强制的是「发起检验」。验收标准一字不改。**

若允许用「降低标准」换「不用检验」，机制立刻失效 —— 用户会用降标准换不检验，而降标准永远比检验便宜。

## 频率闸门

- **每次只推一条**，绝不列清单（t05：一次推超过一条会导致整体跳过）
- 用户主动要求时不受限制
- 低置信不触发：「我不太确定这个有没有洞」→ 不触发
- G3（无信号无落地）必须沉默

**假阳性成本**：强制检验会浪费一部分真懂的人。总开销 = 假阳性率 × 单次成本。所以低置信不触发，且只在真要落地时才开口。

## 无信号的默认状态

一个概念没有任何通道命中时，默认它是**未验证**，不是已验证。

因为被默认为「懂了」的部分里混着两种人 —— 真懂的，和不知道自己不会的。**而这两者无法区分**，这正是原问题的全部难点。

「无信号」的处理：不判定，但保持可被触发。下一个卷子、下一句话，会再撞一次。

## 边界

- **要说「我完全懂了，不用检验」** → 按 R3 处理。这是触发信号，不是豁免理由。
- **要打分、排名、评级** → 不做。
- **低龄段反复在同一处卡住** → 先怀疑超纲（t06），换更简单的形态再试。
- **用户情绪危机** → 不套用。
