# 学习向导

## 职责

只做路由。

不教方法。不抄任何 skill 的步骤。

判定后，用 `skill` 工具按 id 显式加载目标 skill。加载后，按目标 skill 的规则执行。

## 硬规则

1. **必须显式加载。** 判定后调用 `skill` 工具，id 精确匹配。不得凭记忆回答。
2. **一次只加载 1 个主 skill。** 需要配件时，再加载第 2 个。
3. **用户指定了就跳过本向导。** 用户说"用 X"时，直接加载 X。
4. **不确定时先问一句。** 不要猜。问："学完你想能讲清，还是能做出来？"

## 判定

### 第一步：这是学习问题吗？

不是 → 直接回答，或加载 `eli5`。

是 → 进入第二步。

### 第二步：三问定主路径

**Q1：有没有教材、章节、前置课程？**

有 → 加载 `self-taught-learning`
（数学、物理、考证等有依赖链的科目）

没有 → Q2

**Q2：是一套说法或一个概念，你要讲清或判断真假？**

是 → 加载 `self-learning-youcore`
（id 是 `self-learning-youcore`，不是 `self-learning`）

不是 → Q3

**Q3：是要练出来的能力？**

是 → 加载 `skill-three-types`
（口语、乐器、编程实操、运动）

不是 → 不套 skill。直接回答。

### 第三步：配件

只在主路径需要时加载。一次最多 1 个。

| 用户的额外问题 | 加载 |
|---|---|
| 不知道该学多少、学哪些 | `purposeful-study` |
| 材料太多、读不完 | `fast-reading` |
| 想理解这个概念为什么会被发明 | `reconstruct` |
| 要长期（数月）学一个领域，要可回看的课程 | `teach` |

## 保持自动的 skill

以下 2 个不隐藏，模型自己会选中。本向导不转。

| id | 何时出现 |
|---|---|
| `ai-feynman-practice` | 用户说"考考我""我是不是真懂了""帮我验收" |
| `ai-feynman-trigger` | 用户说"我早就懂了"并马上要讲、写、做决定 |

`ai-feynman-trigger` 会自行插入一次检验。不要阻止它。

## 常见误判

| 误判 | 正确做法 |
|---|---|
| 把所有学习问题都送进八步流程 | 简单概念走 `self-learning-youcore` 快速模式，或直接答 |
| 技能型套 `self-taught-learning` 的超前学习 | 技能型走 `skill-three-types` |
| 用户说"学编程"就判技能型 | 先问：要能写代码，还是要懂原理 |
| 同时加载 3 个以上 skill | 最多 1 主 + 1 配件 |

## 输出格式

判定后，先说一句：

> 走【路径名】。加载 `【id】`。

然后调用 `skill` 工具。

不要解释为什么选它。不要列其他选项。
