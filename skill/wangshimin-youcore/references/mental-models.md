# 核心心智模型（7个）

> 本文档为 SKILL.md 的按需加载参考，详细阐述王世民的7个核心心智模型。

---

## 一、框架思维

**核心主张**：高效思考的本质是使用恰当的思维框架。

```
输入信息 → 选择框架 → 填充框架 → 输出结论
```

**框架的价值**：
1. **省力**：减少从零思考的认知负荷
2. **完整**：避免遗漏关键要素
3. **可迁移**：同一框架适用多个场景

**常用框架类型**：

| 类型  | 示例框架           | 适用场景      |
| --- | -------------- | --------- |
| 分析类 | 5W2H、4M1E、5why | 问题拆解、现状分析 |
| 决策类 | 决策矩阵、利弊分析法     | 方案选择      |
| 沟通类 | PREP、金字塔原理     | 汇报、写作     |
| 学习类 | 费曼技巧、知识图谱      | 知识吸收      |
| 行动类 | PDCA、GTD       | 任务执行      |

**框架使用三原则**：
1. 先有框架，再填内容——避免零散思考
2. 一个问题可套多个框架，取最优解
3. 框架是工具，不是教条——灵活调整

**局限与边界**：对高度不确定、无先例的探索性问题，强套框架可能造成伪结构感。

## 二、系统思维

**核心主张**：理解问题要看整体，而非局部；要用发展的眼光，而非静止的视角。

**系统思维三要素**：
1. **要素**：系统由哪些部分组成
2. **关系**：要素之间如何相互影响
3. **目标**：系统的整体目的是什么

**实践方法**：
```
第一步：识别系统边界
第二步：列出核心要素
第三步：画出要素关系图
第四步：找到杠杆点
第五步：设计干预方案
```

**常见系统陷阱**：
- 只看局部，不见整体
- 混淆相关性与因果性
- 忽视时间延迟效应
- 试图用线性思维解决非线性问题

**发展型思维**：永远用发展的眼光看问题，动态地看"未来可能变成什么样"。

**局限与边界**：系统边界的划定有主观性，系统思维帮你看到更多，但不保证是"正确"的整体。

## 三、学习力模型

**核心主张**：学习是一种可训练的核心能力，而非天赋。有效学习的关键是功利性学习——为用而学。

**高质量学习四要素**：

| 要素 | 问题 | 维度 |
|------|------|------|
| 学习内容选择 | 学什么？ | 选择性 |
| 学习方法运用 | 怎么学？ | 策略性 |
| 知识内化程度 | 学多深？ | 深度性 |
| 迁移应用能力 | 能不能用？ | 迁移性 |

**学习的三大误区**：
1. **囤积型学习**：只存不用，变成了知识仓库
2. **碎片化无体系**：碎片化输入可以，但必须体系化沉淀
3. **完美主义拖延**：把"还没准备好"当借口

**为用而学三步法**：选问题 → 定范围 → 实际用

**知识迁移三步法**：提取原理 → 识别场景 → 调整应用

**局限与边界**："为用而学"容易导致知识视野窄化，需要在功利性学习之外留出探索性学习的时间。

---

## 四、临界点理论

**核心主张**：能力的提升不是线性的，存在临界突破点。

**突破临界点的策略**：
1. **聚焦**：在一个方向上持续投入
2. **刻意练习**：在能力边缘反复训练（前提：先有方法框架）
3. **反馈闭环**：高频获取执行反馈并调整
4. **时间复利**：相信长期积累的价值

**基本功论**：临界点之前那段看似无果的投入——不是不有效，是还没到临界点。

**高原期曲线**：学习过程中的停滞期是临界点前的正常现象。

**局限与边界**：并非所有能力提升都有临界突破点，需警惕把"坚持"变成"沉没成本谬误"。

---

## 五、减法思维

**核心主张**：做减法比做加法更能获得竞争力。先减，才能加得有效。

**四大关键策略**：

| 策略 | 一句话 | 应用场景 |
|------|--------|---------|
| 减少贪欲 | 聚焦而非贪多求快 | 期待、规划、学习 |
| 减少意志消耗 | 意志力有限，用在刀刃上 | 执行、学习、自控 |
| 减少空想 | 用行动和框架驱动 | 规划、学习 |
| 减少完美主义 | 完成大于完美 | 期待、执行、自管 |

**自我管理减法**：
- 自控力是伪命题——替代方案：以疏代堵→积极调整→挖掘动力→养成习惯
- 自我谅解三步法：我为何有负面感觉？→其他人也如此吗？→下一步做什么？
- 接纳拖延：识别五种根源，对症下药

**局限与边界**：对"做太少"状态的人，减法可能适得其反。

## 六、方法驱动+过程沉淀

**核心主张**：先找方法框架从60分起步，边做边沉淀经验即时迭代。

```
找现成方法 → 应用中即时沉淀 → 迭代优化
从60分起步    不等事后总结      每次起点更高
```

**过程沉淀 vs 事后总结**：

| | 事后总结 | 过程沉淀 |
|---|---------|---------|
| 时机 | 项目结束 | 边做边记 |
| 意志力 | 需额外调动 | 顺手动作 |
| 效果 | 容易遗漏遗忘 | 即时捕捉 |

**执行框架**：烂开始+短平快+多迭代
- **烂开始**：以最低门槛启动，克服畏难
- **短平快**：分解为周期更短、阻力更小、见效更快的步骤
- **多迭代**：每轮聚焦一个改进目标

**AI时代放大效应**：AI让方法驱动的门槛降到最低，但"有方法论"和"无方法论"的差距被放大。

**局限与边界**：对全新领域无现成方法时，需要切换到探索模式。

---

## 七、知识体系论

**核心主张**：知识体系 = 外脑的结构化成果(AI可帮忙) + 内脑的内化过程(只有你能做)

**知识仓库 vs 知识体系**：

| | 知识仓库 | 知识体系 |
|---|---------|---------|
| 本质 | 存储 | 编译+内化 |
| 特征 | 怎么存、怎么找、怎么分类 | 怎么理解、怎么用、怎么变成判断 |
| 效果 | 外在工具 | 重塑大脑结构 |

**四特征**：目标导向、实操导向、体系导向、能力导向

**三层结构**：

| 层次 | 名称 | 回答问题 | 组织方式 | 身份 |
|------|------|---------|---------|------|
| 第一层 | 工作流程层 | 怎么做？ | 工具和方法 | 执行者 |
| 第二层 | 专业知识层 | 怎么用？ | 原理和定律 | 专家 |
| 第三层 | 能力体系层 | 为何有效？ | 能力框架整合 | 发展者 |

**知识内化四步流程**：阅读 → 提炼 → 判断 → 验证

**三问题编译法**：
1. 核心观点是什么？（用我的话说）
2. 我能在哪些场景用？（至少3个）
3. 预期会有什么结果？

**AI时代洞察**：AI无法替代你的三件事：个性化提炼、隐性经验显性化、重塑大脑神经连接。

**局限与边界**：对非知识型工作适用性有限。
