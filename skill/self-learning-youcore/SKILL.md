# Self-Learning：八步系统学习流程

目标：学完能讲清、能用、能判断。以文件为进度，每步有产物和门槛；门槛不过，不进入下一步。

## 使用场景

| 用 | 不用 |
|---|---|
| 系统学概念、方法或技能 | 简单事实问答、翻译、格式转换 |
| 从理解走到应用 / 判断 / 迁移 | 只需一个快速答案 |
| 判断说法是真拆解还是事后包装 | 纯肌肉记忆，或只需知道名词 |
| 愿投入 1.5–4 小时，分散 1–2 周 | 没有时间做练习 |

## 学习类型判断

启动时先判断学的是哪一类；不确定就问一句：「学完你想能讲清，还是能做出来？」不要默认所有主题都要项目。

| 类型 | 判断标准 | Step 6 交付物 | 需要项目吗 |
|---|---|---|---|
| 概念型 | 学一个概念、理论或说法；目标是讲清、判断真假、写文章 | 考试 + 概念输出验证（向外行解释 + 判断新案例；可选文章/笔记） | **不需要** |
| 方法型 | 学一套可复用的步骤或框架；目标是会用 | 考试 + 项目（真实场景应用方案/案例） | 需要 |
| 技能型 | 学一项需要练习的能力；目标是做到 | 考试 + 项目（实操成果 + 外人按标准验收） | 需要 |

- 混合型以主要目标定：**能讲清 → 概念型；能做出 → 方法型/技能型**。
- **项目**指 1–2 小时的真实场景交付物，须有通过标准、来源表、外人验证。概念型不做这个。
- 概念型的输出验证：用 200 字向外行解释；在 2 个新案例上判断是否成立；外人能复述定义与判据即可，不强制 3 人测试。

## 核心原则

| 原则 | 执行规则 |
|---|---|
| 学习者优先 | 先让学习者写 / 说 / 答；AI 只诊断、补漏；AI 的第一条消息必须是提问或任务，不是讲解 |
| 一次一问 | 等回答后再问下一个；不抛问题串 |
| 文件即状态 | 每步立即写产物；续跑先读已有文件，确认下一步 |
| 来源可追溯 | 关键事实带 `[S#]` 或 `[推断]` / `[待核]`；不编造书名、作者、链接、数据；细则见 source-rules |
| 硬门槛 | 不过就退回补课；不为推进放水 |
| 间隔检索 | 第 1/3/7/14 天闭卷复习；只复习错题 |

## 启动

收集七项；已给的不重复问，缺哪项问哪项。另在 Step 0 判断「学习类型」（概念/方法/技能），不确定时只问一句：

```text
主题 / 为什么学 / 角色与现状 / 已有判断（可选） / 时间预算 / 最终交付物 / 输出位置
```

输出文件夹不存在时先征得同意，再建立：

```text
00-学习契约.md      01-地形图.md       02-矛盾点表.md
03-一页纸.md        04-费曼讲解.md     05-考试与项目.md
06-间隔复习.md      错误日志.md        reference/资源地图.md
reference/S1-<简称>.md …
```

> 概念型的 `05-考试与项目.md` 保留文件名，内容写「考试 + 输出验证」，不设项目。

## 八步执行表

执行某步前读 `references/prompts.md` 对应提示词；产物模板见 `references/templates.md`。

| Step | 名称 | 时长 | 产物 | 关键动作 | 通过门槛 / 不过怎么办 |
|---|---|---|---|---|---|
| 0 | 基线预测试 | 10m | 00-学习契约.md | 闭卷 5 问，一题一问；只记录、标注、追问，不讲解 | 覆盖定义 / 辨析 / 边界 / 应用 / 目标；否则重问 |
| 1 | 资源门控 | 10–15m | 资源地图、S1-*.md | 先让学习者报 2–3 个来源；4 组检索词；A/B/C/D 分级；每源摘要；验证链接 | ≥3 源、≥1 A、≥1 独立反方、每源有摘要、链接可访问；不过→缺口清单，不进 Step 2 |
| 2 | 地形图 + 迷你费曼 | 30–40m | 01-地形图.md | 只读摘要；5 个核心 20%；五级讲；每级先复述；最后 100 字闭卷 | 5 核心各 ≥1 [S#]；复述后才下一级；否则补漏 |
| 3 | 六视角对抗 | 20–30m | 02-矛盾点表.md | 先写反方 / 盲区；V1–V6 各绑来源；对照案例；矛盾点表 | 出现不舒服的反例；每视角 ≥1 [S#]；否则重跑 |
| 4 | 一页纸 | 15–20m | 03-一页纸.md | 先闭卷写 v1；对比标准版；补成 v2 | 5 分钟读完；事实带 [S#] / [推断]；v1 先交；否则重写 |
| 5 | 费曼循环 | 20m | 04-费曼讲解.md | 学习者先讲，禁用主题名；只补卡点；迁移任务 | 外行能懂；不是背原文；否则重讲 |
| 6 | 考试 + 输出验证 | 30–40m | 05-考试与项目.md | 先预测分；10 题递进；按学习类型分流：概念型做输出验证，方法/技能型做项目 | ≥6 分；概念型：外人能复述 + 判断新案例；方法/技能型：项目通过并附来源表；否则补课 |
| 7 | 间隔复习 | 4×10m | 06-间隔复习.md | 第 1/3/7/14 天；5 检索 + 1 迁移；错题回源；更新日志 | 同类错连续 2 次→降级重学；否则继续 |

## Step 6 按类型分流

- **概念型**：考试 → 输出验证。用 200 字向外行解释；在 2 个新案例上判断是否成立；外人能复述定义与判据即通过。**不设项目、不设 1–2 小时交付物、不强制 3 人测试。** 若最终交付物是文章/笔记，可作为可选输出，按普通写作标准验收，不按项目验收。
- **方法型**：考试 → 项目。把方法用在一个真实场景，交应用方案/案例；附来源表；外人能按标准复现或判断。
- **技能型**：考试 → 项目。实际做一次，交实操成果；外人按通过标准验收。
- **共同门槛**：考试 ≥6 分；未过先补课，不进入输出验证/项目。

## 两种模式

| 模式 | 路径 | 时长 | 适用 |
|---|---|---|---|
| 快速 | 0 → 1（2 源）→ 2 → 4 → 6 → 可选 7 | 1.5–2h | 低风险、时间有限 |
| 完整 | 0 → 7 | 2.5–4h，分散 2 周 | 高价值、需迁移 |

快速模式 Step 1 门槛：2 个来源（≥1 A 级 + 1 独立来源），摘要和链接验证不能省。

快速模式 Step 6：概念型只做考试 + 输出验证；方法型/技能型才做项目。

## 文件与续跑

- 每步立即写产物，不留在对话里。
- 续跑：扫描学习文件夹 → 判断已完成的步骤和下一步 → 向用户确认后继续。
- `错误日志.md`：日期、步骤、原话、错在哪层（概念 / 步骤 / 边界 / 迁移）、正确理解、下次如何识别。
- `reference/资源地图.md`：来源唯一入口；后续只读摘要，不重复抓取。

## 结束

全部通过后，按 `references/templates.md` 的「最终验收」逐条检查；**概念型看「能讲清 + 能判断」，方法型/技能型看「能做出来 + 外人可用」**。更新错误日志，安排第 14 天或每月复习，并问用户：继续复习，还是开始新主题。
