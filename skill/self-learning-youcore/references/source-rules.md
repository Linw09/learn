# 来源规则

> 目标：材料可追溯、可复核，防止 AI 把「我记得」写成「事实」。

## 一、来源分级

| 级别 | 类型 | 例子 | 用法 |
|---|---|---|---|
| A | 一手 / 官方 | 原始文件、官方文档、当事人记录、原始数据 | 优先；关键结论至少 1 个 A 级 |
| B | 专家 / 同行评审 | 论文、权威教材、公认专家 | 框架、证据、争议 |
| C | 实践者 / 社区 | 从业者复盘、高声誉社区、访谈 | 现实约束、操作细节 |
| D | 营销 / SEO | 卖课页、无来源情绪文、纯流量内容 | 排除 |

A 级判断：这份材料是「事情发生时留下的原始记录」，不是「后来某人的转述」。

## 二、产物

### 资源地图

保存到 `reference/资源地图.md`，字段固定：

```text
| ID | 级别 | 类型 | 标题 | 作者/机构 | 日期 | 链接 | 覆盖内容 | 适用步骤 | 备注 |
```

- ID 从 S1 递增；后续引用只用 ID。
- 日期写发布或更新日期；没有就写「未标注」，不要猜。
- 备注写「强在哪、局限在哪」。
- 末尾写「资源使用说明」：谁支撑哪一步、谁是反方、谁有局限。

### 结构化摘要

每个来源一份，保存到 `reference/S1-<简称>.md`，300–800 字，五段：核心观点 / 关键框架 / 可用数据 / 适用场景 / 局限。模板见 `templates.md`。

## 三、引用

| 规则 | 写法 / 要求 |
|---|---|
| 事实 | `[S1]` |
| 推断 | `[推断]` |
| 未核实 | `[待核]` |
| 多来源 | `[S1][S3]` |
| 一手优先 | 只有二手摘要时注明「转引自 S2，原文未获取」 |
| 数据 | 「数值（日期，口径，[S#]）」 |
| 无来源的关键事实 | 不得进入一页纸和费曼稿；补检索或降级为 `[推断]` |
| 禁止空泛归因 | 不用「研究表明」「专家认为」代替具体来源 |

**每步最低引用**：

| 步骤 | 最低要求 |
|---|---|
| Step 2 地形图 | 5 个核心概念各 ≥1 个 [S#] |
| Step 3 六视角 | 每个视角 ≥1 个 [S#]；V6 例外，但必须写具体 |
| Step 4 一页纸 | 所有事实和数字带 [S#] 或 [推断] |
| Step 5 费曼稿 | 关键机制 ≥1 个 [S#] |
| Step 6 项目 | 交付物附来源表 |

## 四、检索

| 顺序 | 方法 | 失败处理 |
|---|---|---|
| 1 | 内置搜索，拿候选 URL | 换下一渠道 |
| 2 | 直接抓取（HTTP / 内置网页读取） | 换下一渠道 |
| 3 | 渲染抓取（JS 页面、登录页用浏览器或代理） | 换下一渠道 |
| 4 | 本地兜底（命令行工具提取正文） | 标 `[未获取]` |

**检索词至少四类**：

```text
官方 / 一手：<主题> official documentation / 官方文档 / 原始论文
系统综述 / 教材：<主题> systematic review / 综述 / 教科书
独立批评 / 反方：<主题> criticism / limitations / 争议 / 反例
实践者 / 社区：<主题> practitioner / 复盘 / 高声誉社区
```

- 中文主题至少 1 个中文来源：公众号、知乎、B 站、行业媒体、中文期刊。
- 链接 2xx / 3xx 才算可访问；404 / 410 是死链。
- 打开原文核对关键点，不能只信搜索摘要；作者、机构、日期对不上标 `[待核]`。
- 某渠道失败就换；全失败写「外部资源未获取」，说明哪些步骤缺支撑。
- 不得用记忆补来源、书名、数据；不要把代理地址或特定站点写进通用流程。

## 五、质量检查与常见错误

| 检查项 | 标准 | 常见错误 |
|---|---|---|
| 来源数量 | ≥3 个外部来源 | 一个来源反复用，不算多样性 |
| 来源级别 | ≥1 个 A 级来源 | 把二手转述当一手 |
| 反方 | ≥1 个独立批评 / 反方 | 用支持方的自我批评充数 |
| 摘要 | 每源 300–800 字，五段齐全 | 只抄搜索摘要 |
| 链接 | 可访问，关键点在原文 | 不打开原文就引用 |
| 数据 | 带日期、口径、[S#] | 数字没有日期和口径 |
| 空白 | 无未解决项；缺失标 `[未获取]` | 用 AI 推测补缺口 |
| 六视角 | 每视角有来源或标 `[推断]` | 六个 AI 角色聊天 |
