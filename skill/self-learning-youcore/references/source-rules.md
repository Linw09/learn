# 材料与来源规则

> 只在两种时候读：要补检索，或要判断一个来源能不能信。

## 一、手头材料优先

| 情况 | 做法 |
|---|---|
| 我给了书 / 文档 / 课程 / 文章 | 当主材料，直接读；来源表里写一句「强在哪、局限在哪」 |
| 我给了名字或链接 | 先确认拿得到；拿不到标 `[未获取]`，按名字如实转述 |
| 我什么都没给 | 按第三节检索 |
| 材料撑不起 5 个核心 | 补 2–3 个来源，并说明哪块缺支撑 |

## 二、来源分级

| 级别 | 类型 | 例子 | 用法 |
|---|---|---|---|
| A | 一手 / 官方 | 原始文件、官方文档、当事人记录、原始数据 | 优先；关键结论至少 1 个 A 级 |
| B | 专家 / 同行评审 | 论文、权威教材、公认专家 | 框架、证据、争议 |
| C | 实践者 / 社区 | 从业者复盘、高声誉社区、访谈 | 现实约束、操作细节 |
| D | 营销 / SEO | 卖课页、无来源情绪文、纯流量内容 | 排除 |

A 级判据：这是「事情发生时留下的原始记录」，而不是「后来某人的转述」。

## 三、检索词（四类都试一轮）

```text
官方 / 一手：<主题> official documentation / 官方文档 / 原始论文
系统综述 / 教材：<主题> systematic review / 综述 / 教科书
独立批评 / 反方：<主题> criticism / limitations / 争议 / 反例
实践者 / 社区：<主题> practitioner / 复盘 / 高声誉社区
```

- 中文主题至少 1 个中文来源：公众号、知乎、B 站、行业媒体、中文期刊。
- 链接 2xx / 3xx 才算可访问；404 / 410 是死链。
- 打开原文核对关键点，别只信搜索摘要；作者、机构、日期对不上标 `[待核]`。
- 换个渠道再试；全失败就写「外部资源未获取」，并说明哪几步缺支撑。
- 书名、作者、数据都从原文取，记忆里的一律标 `[推断]`。

## 四、来源表

写在 `01-地形图.md` 末尾（格式见 templates.md），是全部来源的唯一入口；后续步骤只读它，不重复抓取。

- ID 从 S1 递增，后文只引 ID。
- 日期写发布或更新日期；没有就写「未标注」。
- 补检索来的来源另写 ≤300 字摘要，存 `reference/材料/S1-<简称>.md`；我原有的材料不写摘要。

## 五、引用标签

| 情况 | 写法 |
|---|---|
| 事实 | `[S1]` |
| 推断 | `[推断]` |
| 未核实 | `[待核]` |
| 多来源 | `[S1][S3]` |
| 转引 | 「转引自 S2，原文未获取」 |
| 数据 | 「数值（日期，口径，[S#]）」 |
| 关键事实无来源 | 补检索，或降级为 `[推断]`，不进一页纸和费曼稿 |
| 空泛归因 | 「研究表明」「专家认为」换成具体来源 |

**每步最低引用**：

| 步骤 | 最低要求 |
|---|---|
| Step 1 地形图 | 5 个核心概念各 ≥1 个 [S#] |
| Step 2 六视角 | 每个视角 ≥1 个 [S#]（V6 例外，要写具体） |
| Step 3 一页纸 | 所有事实和数字带 [S#] 或 [推断] |
| Step 4 费曼稿 | 关键机制 ≥1 个 [S#] |
| Step 5 项目 | 交付物附来源表 |

## 六、质量检查

| 检查项 | 标准 | 常见错法 |
|---|---|---|
| 数量 | 补检索时 2–3 个，作者不重复 | 一个来源反复用，当成多样性 |
| 级别 | 关键结论至少 1 个 A 级 | 把二手转述当一手 |
| 反方 | 至少 1 个独立批评 | 用支持方的自我批评充数 |
| 摘要 | 补检索来源 ≤300 字，五段齐全 | 只抄搜索摘要 |
| 链接 | 能打开，关键点在原文 | 不打开原文就引用 |
| 数据 | 带日期、口径、[S#] | 数字没有日期和口径 |
| 缺口 | 标 `[未获取]` / `[待补]` | 用推测把洞填平 |
| 六视角 | 每视角有来源或标 `[推断]` | 六个 AI 角色轮流聊天 |
